# Built with RepoSource Registry

The project welcomes real downstream tools, analyses, and research that use the public registry.

## Submission criteria

A showcase entry should:

- use RepoSource Registry data in a meaningful way;
- provide a public project or research link;
- identify the dataset or snapshot used where reproducibility matters;
- describe the use briefly and factually.

## What inclusion means

Showcase inclusion documents community usage. It does not imply endorsement, partnership, ranking, sponsorship benefit, review, or guaranteed promotion.

## Suggested submission format

```text
Project:
URL:
What it builds:
RepoSource usage:
Dataset/snapshot:
Notes:
```

Submissions can be proposed through GitHub issues when a suitable community workflow is available.

No fictional projects or placeholder testimonials should be published as evidence of adoption.
