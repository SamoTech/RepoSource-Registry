# Commercial use

RepoSource Registry is open-source infrastructure. Commercial use of the project and its public data must follow the actual project license, upstream GitHub terms, and any licenses or restrictions applicable to individual repository metadata.

## What remains public

The canonical RepoSource dataset, schema, metadata, methodology, and published documentation remain available as open project infrastructure.

Commercial services do not require removing the usefulness of these public resources.

## Legitimate commercial work around the dataset

Commercial engagements may provide:

- data integration;
- custom processing and engineering;
- AI/RAG implementation;
- research and ecosystem analysis;
- analytical reports;
- hosted discovery or visualization experiences;
- organization-specific integrations;
- technical support and implementation services.

The customer pays for expertise, implementation, customization, research, analytics, or hosted functionality.

## What is not for sale

The project does not sell:

- private user information;
- hidden repository rankings;
- repository inclusion or suppression;
- sponsor influence over collection or classification;
- fabricated authority or endorsements;
- artificial restrictions on the canonical public dataset.

## Public-data integrity

Customer or sponsor requirements must not silently modify the canonical public registry. Custom datasets and research outputs should be clearly identified as derived or customer-specific work.

## Licensing boundary

The MIT License applies to the project code and documentation as stated in [`LICENSE`](../LICENSE). Repository metadata obtained from GitHub is not automatically covered by that project license; downstream users are responsible for respecting the relevant upstream terms and applicable law.
