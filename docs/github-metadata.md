# GitHub repository metadata recommendations

These recommendations are for the repository About section and are documented because repository UI metadata is separate from the file-generation pipeline.

Suggested description:

Open, machine-readable GitHub repository discovery dataset with weekly snapshots, schema validation, provenance, and language/category indexes.

Suggested topics:

- github
- github-api
- github-search
- repository-dataset
- repository-registry
- open-source
- developer-tools
- dataset
- machine-readable-data
- repository-discovery

A future hosted discovery site could become the homepage. Until then, the GitHub repository remains the canonical project surface.

A future social preview should communicate structured public repository discovery data and must not imply official GitHub affiliation or guaranteed completeness.
